## Vision

### 10x Check
Transform a qualifying Kaggle hackathon entry into an institutional-grade, reproducible competitive machine learning pipeline. Rather than tweaking a single notebook and hoping for a good public score, we establish an end-to-end framework: leak-free retail feature engineering, stratified 5-fold cross-validation, a multi-model heterogeneous ensemble (LightGBM + XGBoost + CatBoost + Ridge) with SciPy-optimized blending weights, post-processing sanity checks, and an executive methodology report. This guarantees local validation fidelity, insulates against private leaderboard shakeups, and fulfills DSN's qualifying criteria: "Understand → Analyse → Model → Predict → Communicate".

### Platonic Ideal
A production-grade machine learning repository where:
1. `src/` modularizes data loading, feature transformations, cross-validation, modeling, and submission verification.
2. A single orchestrator command (`python src/train_ensemble.py`) runs 5-fold CV across 3 gradient boosting architectures, logs exact OOF RMSE, computes optimal blending weights, produces clean feature importances, and exports a verified submission file.
3. Every transformation has zero leakage, handles missing values deterministically from domain properties, and guarantees non-negative sales predictions.
4. Assessor-ready documentation explains every data science decision and demonstrates domain mastery to the DSN selection committee.

## Accepted Scope (added to this plan)
- Data pipeline recovering `product_weight_kg` from item dictionary and `store_size` from store tier/format profiles.
- Zero-visibility correction and category text standardization.
- Price interaction features (`product_price * shelf_visibility`, store-relative price ratios, estimated units sold).
- Stratified / K-Fold CV pipeline with out-of-fold scoring and fold-by-fold validation tracking.
- LightGBM, XGBoost, and CatBoost regressors trained on identical CV splits.
- Ensemble optimizer finding constrained convex weights to minimize out-of-fold RMSE.
- Submission export and automated sanity checker (`validate_submission.py`).
- Comprehensive EDA & Methodology document (`docs/methodology_report.md`).
